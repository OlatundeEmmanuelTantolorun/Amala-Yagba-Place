# Amala Yagba Place

Standalone Vite + React project.

## Start fresh

1. Extract this folder.
2. Open a terminal in this project folder (the folder containing `package.json`).
3. Run:

   ```bash
   npm install
   npm run dev
   ```

## Production check

```bash
npm run build
npm run preview
```

`node_modules` is intentionally not included. `npm install` recreates it from `package.json` and `package-lock.json`.
